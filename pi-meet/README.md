# 3,14 — θα ξανασυναντηθούμε

Μία σελίδα, ένα αρχείο (`index.html`), χωρίς build και χωρίς εξαρτήσεις (μόνο η γραμματοσειρά από Google Fonts).

Δύο βραχίονες γυρίζουν· ο δεύτερος γυρίζει **k** φορές πιο γρήγορα από τον πρώτο: `z(t) = e^{it} + e^{ikt}`.

- **k = 3,14 = 157/50** → μετά από ακριβώς 50 γύρους η άκρη γυρίζει στο σημείο που ξεκίνησε: «θα ξανασυναντηθούμε».
- **k = π** (άρρητος) → ο δρόμος δεν κλείνει ποτέ, αλλά περνά όλο και πιο κοντά (γύρος 7, 113, 33.215…).

## Παράμετροι URL

| παράμετρος | τι κάνει |
|---|---|
| `?mode=pi` | ξεκινά με το π αντί για 3,14 |
| `?lang=en` | αγγλικά |
| `?speed=2` | ταχύτητα (0.25 – 4) |
| `?embed=1` | κρύβει τα κουμπιά (για iframe) |
| `?loop=0` | δεν ξαναρχίζει μόνο του μετά τη συνάντηση |

## Πώς το βάζεις στο δικό σου site

**Ως ξεχωριστή σελίδα** (π.χ. React/Vercel): αντέγραψε το `index.html` στο `public/pi/index.html`
και θα είναι διαθέσιμο στο `https://<site>/pi/`.

**Μέσα σε μια υπάρχουσα σελίδα:**

```html
<iframe src="/pi/index.html?embed=1" style="width:100%;height:100vh;border:0" title="3,14"></iframe>
```

# `chance.html` — «Πάντα υπάρχει μια πιθανότητα»

Μια εμπειρία-ιστορία που τη στέλνεις σε κάποιον/κάποια με ένα link.

1. **Builder** (ανοίγεις σκέτο το `chance.html`): γράφεις για ποιον/ποια είναι, από ποιον, την ερώτηση και πόσες φορές έχεις ήδη ρωτήσει. Βγαίνει ένα link.
   Όλα αυτά μπαίνουν μέσα στο `#` του link, οπότε δεν πάνε σε κανέναν server και δεν αποθηκεύονται πουθενά.
2. **Ο παραλήπτης/Η παραλήπτρια** βλέπει το όνομά του/της, αγγίζει την οθόνη (ξεκινά και ένας ήχος) και το π αρχίζει να ζωγραφίζει.
   Κάθε γύρος είναι μια «προσπάθεια». Στην 7η προσπάθεια ανοίγει ένας **μεγεθυντικός φακός** που κάνει zoom στη χρυσή κουκκίδα,
   για να φανεί ότι η γραμμή πέρασε μόλις 0,0045% μακριά.
3. Το **θεώρημα του Dirichlet**: όσο κοντά κι αν ορίσεις, κάποια προσπάθεια θα φτάσει εκεί. Ο παραλήπτης/Η παραλήπτρια το δοκιμάζει μόνος/μόνη του/της με ένα slider
   (1% … 10⁻²⁶ %). Η σελίδα πηγαίνει στην πραγματική προσπάθεια (113, 33.215, … 567.663.097.408) και κάνει zoom ×10²⁶.
   Οι προσπάθειες αυτές είναι οι παρονομαστές του συνεχούς κλάσματος του π, υπολογισμένοι με ακρίβεια 100 ψηφίων.
4. **Η ερώτηση.** «Ναι»: το π μεταμορφώνεται ζωντανά σε 3,14, ο κύκλος κλείνει πάνω στη χρυσή κουκκίδα, ο ήχος «λύνεται» σε συγχορδία και το κινητό δονείται.
   «Όχι ακόμα»: γίνεται σεβαστό· ο κύκλος συνεχίζει ήσυχα να γυρίζει. Και στις δύο περιπτώσεις υπάρχει κουμπί για να σταλεί η απάντηση.

Για δοκιμές: `chance.html?speed=6` τρέχει την ιστορία πιο γρήγορα.
